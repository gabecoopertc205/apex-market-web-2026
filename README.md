## Frequently Asked Questions

**What is the simplest way to view the site?**  
Open the main HTML file with a browser, or serve the project directory from a static web server.

**May I change the website content?**  
Yes. Update the HTML and its associated assets, save the files, and refresh the page to inspect the changes.

**Where does the configuration live?**  
With an HTML-based site, configuration is generally found in the page markup and the files referenced by that markup.
